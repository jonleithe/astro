Detailed Description

Approximate Schlyter lunar orbit with major perturbations, equinox of date.

Note
Includes WGS-84 observer parallax/height. Uses UTC as UT; omits TT, nutation, aberration, light-time and terrain. Intended for visualization near 1900-2100, not precision ephemerides. Invalid UTC fields throw std::invalid_argument.
