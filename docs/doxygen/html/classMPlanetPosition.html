Detailed Description

Approximate Keplerian planetary positions, equinox of date.

Note
Uses Schlyter elements near 1900-2100; includes WGS-84 observer parallax/height, but omits light-time, aberration, nutation, refraction, terrain and TT/UT differences. Not a precision ephemeris.
