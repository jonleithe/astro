Detailed Description

In-memory skyline cache built once for an observer and DEM.

Note
ASCII input must be a north-up ESRI grid in WGS-84 longitude/latitude degrees with ellipsoidal heights in metres. No vertical datum conversion, sea-surface filling, refraction or terrain-aware event calculation is applied.
